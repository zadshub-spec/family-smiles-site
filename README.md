# Siri Family Smiles

Build a modern, professional, trustworthy dental clinic website for:

Siri Family Dental

May Pen, Jamaica

Business information:

- Address: National Bank, Fernleigh Avenue Upstairs, 45 A Main Street, May Pen, Jamaica

- Phone: +1 876-774-6645

- Opening Hours: Monday to Saturday, 9:00 AM - 5:00 PM

- Sunday: Closed

Website goal:

Create a warm, clean and professional dental website that makes patients feel comfortable and confident about booking an appointment.

Design direction:

- Modern dental/healthcare aesthetic

- Clean white background

- Soft blue and teal accents

- Plenty of whitespace

- Rounded cards and buttons

- Professional but friendly

- Family-oriented feeling

- High-quality dental imagery

- Clear typography

- Excellent mobile responsiveness

- Avoid an overly corporate or hospital-like appearance

Target audience:

- Families

- Adults

- Children

- Patients looking for general dental care

- Patients looking for cosmetic and restorative dental services

Important:

Do not invent doctors, qualifications, services, prices, testimonials, awards or medical claims that are not provided.

Create the project with:

- Responsive desktop design

- Tablet responsiveness

- Mobile-first layout

- Accessible color contrast

- SEO-friendly structure

- Fast loading

- Clear navigation

- Reusable components

- Clean code structure
